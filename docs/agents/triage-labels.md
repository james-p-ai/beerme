# Triage label vocabulary

Category (one per issue):

| Role | GitHub label |
|------|----------------|
| bug | `bug` |
| enhancement | `enhancement` |

State (one per issue):

| Role | GitHub label |
|------|----------------|
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

BeerMe-specific:

| Label | Use |
|-------|-----|
| `prd:v1.0.0` | Pinned PRD version |
| `phase-1-foundation` | Phase milestone |
| `phase-2-taste-engine` | Phase milestone |
| `phase-3-catalog-recs` | Phase milestone |
| `ralph` | Ralph loop batch pending Verify |
| `size:S` / `size:M` / `size:L` | Ticket size |
